# Установка и обновление 0.6.3

Текущая версия поставляется переносимым ZIP как в 0.5.3. Собственных VoxPad.exe, InstallWorker.exe и EXE-установщика в этом комплекте нет. Интерфейс Qt Quick и функции текущей версии сохранены.

1. Скачайте `VoxPad-0.6.3-Windows-x64-portable.zip` со [страницы релиза](https://github.com/Skrxtch-eds/VoxPad/releases/tag/v0.6.3).
2. Выберите «Извлечь всё» и дождитесь полной распаковки в папку, доступную для записи.
3. Откройте извлечённую папку VoxPad и запустите **VoxPad.cmd**.

Python, библиотеки и модель включены; устанавливать Python или .NET Framework отдельно не нужно. Для ZIP и распаковки оставьте не менее 4 ГБ. Интернет нужен для получения ZIP, а для запуска и диктовки не нужен. Папки runtime, app, models и launch.py должны оставаться рядом с CMD. Не запускайте CMD внутри архива.

История и настройки находятся в data рядом с CMD. Для обновления завершите прежний VoxPad через трей, распакуйте новую версию отдельно и скопируйте прежнюю data до первого запуска. У установленной 0.6.2 это обычно `%LOCALAPPDATA%\Programs\VoxPad\data`. Перед заменой существующей data сохраните её копию; автоматического объединения историй нет.

Автозапуск выключен по умолчанию. Если он был включён в старой версии, сначала выключите его в ней; затем при необходимости включите заново в настройках новой версии. Ярлык для VoxPad.cmd можно создать средствами Проводника. При перемещении папки также перенастройте автозапуск.

При ошибке приложения используйте VoxPad-debug.cmd; подробности сохраняются в data/startup-error.log. Для удаления выключите автозапуск, завершите VoxPad через трей и удалите переносимую папку, предварительно сохранив data при необходимости.

Настройки защиты Windows не меняются. Сторонние библиотеки могут оставаться неподписанными; переносимый формат не гарантирует разрешение Smart App Control на каждом компьютере.

Ниже сохранена инструкция для **прежнего EXE-установщика 0.6.2**. Его файлы не включены в portable-релиз 0.6.3.

# Прежний EXE-установщик 0.6.2

## Требования

Windows 10/11 x64, микрофон, .NET Framework 4.8 из Windows, интернет во время установки, не менее 4 ГБ свободного места на диске установки. Распознавание работает на CPU. Python поставляется с программой.

## Установка

Откройте VoxPad-0.6.2-Setup-x64.exe. На одном экране NSIS-установщика выберите родительскую папку и переключатели ярлыков на рабочем столе, в меню «Пуск» и запуска вместе с Windows. Все три переключателя изначально включены. Нажмите «Установить»: установщик скачает полный ZIP с GitHub Releases по HTTPS, сверит закреплённый SHA-256 и распакует компоненты. До начала установки окно можно закрыть; во время загрузки и распаковки дождитесь завершения. При сетевой ошибке повторите установку. Возобновления частичной загрузки пока нет.

В выбранной папке создаётся отдельная папка VoxPad; итоговый путь показан под полем выбора. Например, выбор D:\Apps даст D:\Apps\VoxPad. Каталог по умолчанию — %LOCALAPPDATA%\Programs\VoxPad. В нём находятся VoxPad.exe, Uninstall.exe, current.txt, служебная папка .setup, папка пользовательских данных data и версии в versions/0.6.2. Внутри версии находятся runtime, app, models, launch.py, installed.flag, BUILD-MANIFEST.json и лицензии. Программа появляется в списке установленных приложений Windows.

Для запуска из папки откройте VoxPad.exe. Ярлыки и автозапуск также используют этот EXE. При запуске вместе с Windows окно скрыто в трее. Выбор автозапуска сохраняется в data/settings.json и отображается в настройках приложения; другие настройки и история при повторной установке сохраняются.

## Обновление

Закройте VoxPad через трей и запустите установщик новой версии. Данные находятся в общей папке data. Файлы каждой версии устанавливаются отдельно, current.txt переключает лаунчер после распаковки. Старые каталоги версий сохраняются до удаления приложения и занимают дополнительное место.

Повторная установка той же версии использует существующий каталог. Для восстановления повреждённых файлов сохраните data, удалите приложение и установите его заново.

Для переноса из portable закройте обе программы и скопируйте прежнюю data в %LOCALAPPDATA%\Programs\VoxPad\data до запуска установленной программы. Перед заменой существующей базы сохраните её копию. Автоматического объединения двух историй нет.

## Portable и офлайн-установка

Извлеките весь ZIP и запустите VoxPad.exe. История и настройки сохраняются в data рядом с EXE. ZIP можно заранее перенести на компьютер без интернета. Для обновления распакуйте новую версию отдельно и перенесите data.

## Удаление

Удалите VoxPad в настройках Windows или запустите Uninstall.exe. Удаляются версии, модели, лаунчер, ярлыки и принадлежащая этой установке запись автозапуска. Папка data сохраняется. Для полного удаления личных данных удалите её вручную.

## Автоматический запуск установщика

```powershell
VoxPad-0.6.2-Setup-x64.exe /S
VoxPad-0.6.2-Setup-x64.exe /S /DESKTOP=0 /STARTMENU=1 /AUTOSTART=1 /D=D:\Apps\VoxPad
VoxPad-0.6.2-Setup-x64.exe /S /TESTMODE /ARCHIVE="C:\Downloads\VoxPad-0.6.2-Windows-x64-runtime.zip" /D=C:\VoxPadTest\VoxPad
```

/ARCHIVE использует локальный ZIP с закреплённой суммой. /TESTMODE отключает ярлыки, регистрацию приложения и запись автозапуска в реестр; он предназначен для отдельного тестового каталога. /DESKTOP, /STARTMENU и /AUTOSTART принимают 0 или 1. /D задаёт точную папку приложения, ставится последним и не обрамляется кавычками даже при пробелах в пути. Код возврата 0 означает успех, 1 — ошибку установки, 2 — запущенный VoxPad. Дождитесь завершения процесса; в PowerShell используйте Start-Process -Wait -PassThru. Подробности ошибки находятся в %TEMP%\VoxPad-setup-error.log. Тихое удаление: Uninstall.exe /S.

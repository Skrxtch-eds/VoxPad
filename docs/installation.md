# Установка и обновление 0.6.0

## Требования

Windows 10/11 x64, микрофон, .NET Framework 4.8 из Windows, интернет во время установки, не менее 4 ГБ свободного места на диске установки. Распознавание работает на CPU. Python поставляется с программой.

## Установка

Скачайте VoxPad-0.6.0-Setup-x64.exe из [релиза](https://github.com/Skrxtch-eds/VoxPad/releases/tag/v0.6.0) и нажмите «Установить». Он скачивает полный ZIP с GitHub Releases по HTTPS, сверяет закреплённый SHA-256 и распаковывает компоненты. Загрузка и распаковка поддерживают отмену. При сетевой ошибке повторите установку. Возобновления частичной загрузки пока нет.

Каталог по умолчанию — %LOCALAPPDATA%\Programs\VoxPad. В нём находятся VoxPad.exe, Uninstall.exe, current.txt, папка пользовательских данных data и версии в versions/0.6.0. Внутри версии находятся runtime, app, models, launch.py, installed.flag, BUILD-MANIFEST.json и лицензии. Ярлыки создаются в меню «Пуск» и на рабочем столе. Программа появляется в списке установленных приложений Windows.

## Обновление

Закройте VoxPad через трей и запустите установщик новой версии. Данные находятся в общей папке data. Файлы каждой версии устанавливаются отдельно, current.txt переключает лаунчер после распаковки. Старые каталоги версий сохраняются до удаления приложения и занимают дополнительное место.

Повторная установка той же версии использует существующий каталог. Для восстановления повреждённых файлов сохраните data, удалите приложение и установите его заново.

Для переноса из portable закройте обе программы и скопируйте прежнюю data в %LOCALAPPDATA%\Programs\VoxPad\data до запуска установленной программы. Перед заменой существующей базы сохраните её копию. Автоматического объединения двух историй нет.

## Portable и офлайн-установка

Извлеките весь ZIP и запустите VoxPad.exe. История и настройки сохраняются в data рядом с EXE. ZIP можно заранее перенести на компьютер без интернета. Для обновления распакуйте новую версию отдельно и перенесите data.

## Удаление

Удалите VoxPad в настройках Windows или запустите Uninstall.exe. Удаляются версии, модели, лаунчер, ярлыки и принадлежащая этой установке запись автозапуска. Папка data сохраняется. Для полного удаления личных данных удалите её вручную.

## Автоматический запуск установщика

```powershell
VoxPad-0.6.0-Setup-x64.exe --silent
VoxPad-0.6.0-Setup-x64.exe --silent --test-mode --target=C:\VoxPadTest --archive=C:\Downloads\VoxPad-0.6.0-Windows-x64-runtime.zip
```

--archive использует локальный ZIP с закреплённой суммой. --test-mode отключает ярлыки и регистрацию приложения. --target выбирает отдельную папку. Код возврата 0 означает успех, 1 — ошибку. Дождитесь завершения процесса. Отчёт ошибки находится в %TEMP%\VoxPad-setup-error.log.

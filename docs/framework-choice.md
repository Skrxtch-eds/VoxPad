# Выбор фреймворка для переработки VoxPad

Дата: 17 ноября 2026 года.

Пользователь выбрал PySide6 + Qt Quick/QML для будущей переработки приложения. Основной движок распознавания и прикладная логика сохраняются на Python; интерфейс и его связь с движком будут переработаны.

## Приоритеты

- Современный внешний вид.
- Удобная установка на Windows без отдельной установки Python пользователем.
- Контроль потребления памяти.
- Сначала Windows; в перспективе возможны macOS и Linux.

## Ориентиры реализации

- PySide6 — интеграция Qt с Python; Qt Quick/QML — интерфейс и панель записи.
- Сохранить существующую логику распознавания, работы с аудио и хранения данных, адаптируя её связь с новым интерфейсом.
- Горячие клавиши, вставку текста и другие системные функции отделять от интерфейса для возможного переноса на другие ОС.
- Подготовить обычный установщик и обновление с сохранением истории, настроек и модели. Упаковка и установка требуют отдельной работы.
- Не считать переход на Qt гарантией снижения памяти: измерять расход интерфейса и движка отдельно, включая простой и распознавание.
- Перед полным переносом проверить прототип главного окна, панели записи и одной настоящей диктовки; измерить память и проверить пробную установку.

Это сохранённое направление будущей переработки. Текущая реализация остаётся на Tkinter до отдельной задачи на перенос.

# Проверка VoxPad 0.6.1

Сборка использует официальный Python 3.14.10, подписанный Python Software Foundation, и Pillow 13.0.0. Детали проверки безопасности находятся в [отчёте](security-review-2026-11-18.md).

## Результаты 18 ноября 2026 года

- 129 модульных тестов и QML smoke прошли.
- Сверены 4689 файлов манифеста полного ZIP.
- Комплектный runtime выполнил реальное распознавание публичной русской записи и корректно завершился.
- EXE-установщик отклонил ZIP с неверным SHA-256 без изменения пользовательских данных.
- Установка, повтор установки и удаление прошли, общая data сохранилась.
- Сигнатурный поиск секретов и проверка лишних файлов ZIP не дали совпадений.
- OSV не вернул известных уязвимостей для 12 версий из манифеста.
- Defender проверил Setup и runtime с кодом 0, found no threats.

SHA-256 полного ZIP — e64797b962ed7a528fd6a7bfcdd9b3337212f50aa352d4154d328943f9d10b1f.

Модульные проверки выполняются на том же Python, который используется для сборки. Проверка дистрибутива включает SHA-256 файлов, EXE-установку в папку с кириллицей, запуск через лаунчер, реальное распознавание публичной записи, повторную установку, сохранение data и удаление программы.

Перед публикацией проверяются зависимости через OSV, токены известных форматов и нежелательные файлы в ZIP, а также выполняется сканирование Defender. Публичная загрузка установщика проверяется после публикации.

Тестирование выполняется на компьютере разработчика. Физический микрофон, все приложения назначения и чистая виртуальная Windows имеют отдельный охват.

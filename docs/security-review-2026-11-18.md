# Проверка безопасности 18 ноября 2026 года

## Проверенный охват

Проверены текущие отслеживаемые файлы, приложение и установщик, формирование дистрибутива, сетевые адреса, буфер обмена, настройки, SQLite, обработчик клавиши, локальная диагностика и содержимое полного ZIP. Версии всех 12 поставляемых Python-дистрибутивов запрошены в OSV.

## Найдено и исправлено в 0.6.1

1. Сборщик копировал Python среды разработки, подписанный OpenAI. В стандартной библиотеке находились изменённый ssl.py и codex-rejected-cas.pem. PEM содержал публичный сертификат с дополнительной политикой доверия, приватного ключа в нём не было. Runtime заменён на официальный Python 3.14.10, при сборке проверяются подписи Python Software Foundation.
2. Для Pillow 12.3.0 OSV вернул известные уязвимости. Версия обновлена до 13.0.0. Основной сценарий VoxPad создаёт изображения в памяти и не предоставляет импорт пользовательских картинок, однако уязвимая библиотека удалена из нового дистрибутива.
3. Миграция настроек сохраняла произвольные неизвестные поля. Теперь используются только поля DEFAULTS, поэтому старые секреты и посторонние значения не попадут в новый JSON при сохранении. Подлинные повреждённые настройки и личные данные пользователя автоматически не удаляются.
4. Скрипт публикации мог использовать произвольный HTTPS-адрес с GitHub-токеном. Теперь разрешены только api.github.com и uploads.github.com, перенаправления за их пределы отклоняются до передачи авторизации.
5. Из текущего отчёта дизайна убран локальный персональный путь.

## Проверки данных

В проверенных файлах не обнаружены токены GitHub, OpenAI, Hugging Face, AWS, приватные ключи и URL со встроенными логином/паролем. Шаблонный поиск выводит только имя файла, строку и тип совпадения. Значения совпадений не печатаются.

В релизный комплект не должны входить settings.json пользователя, SQLite, резервное аудио, .env, приватные сертификаты и настройки среды Codex. Исходные модели Parakeet и её tokens.txt являются необходимыми ресурсами распознавания.

История приложения хранится в SQLite без шифрования. Текст автоматически копируется в буфер обмена, на который распространяются настройки Windows. Эти свойства описаны в privacy.md.

## Зависимости и сеть

После обновления OSV не вернул известных уязвимостей для проверенных 12 версий Python-пакетов. Это результат базы на дату проверки. Бинарные зависимости Qt, ONNX Runtime, OpenSSL и Windows требуют отдельного анализа их состава и применимости CVE.

Приложение загружает отсутствующую модель с закреплённой ревизии Hugging Face с проверкой размеров и SHA-256. Установщик загружает полный комплект с GitHub по HTTPS и сверяет закреплённый SHA-256 до распаковки. Сетевая проверка OSV выполняется инструментом разработчика и передаёт только названия и версии пакетов.

## Воспроизведение

Используйте официальный Python 3.14.10 с requirements-build.txt.

```powershell
python -m unittest discover -s tests -p "test_*.py"
python scripts/security_check.py --archive outputs/VoxPad-0.6.1-Windows-x64-runtime.zip --osv --report work/security-review.json
```

Также выполняются проверка целостности полного ZIP, реальный запуск комплектного runtime, распознавание тестовой записи, EXE-установка, повторная установка, сохранение data и удаление. Проверка Defender относится к конкретным проверенным файлам.

## Границы

Проверка исходников, сигнатур секретов и OSV не является доказательством отсутствия любых уязвимостей. Динамический анализ сторонних native-библиотек, независимый аудит и проверка на чистой виртуальной Windows имеют отдельный охват. История Git сохраняет прежние коммиты, включая удалённый из текущих файлов локальный путь. Переписывание истории не выполнялось.

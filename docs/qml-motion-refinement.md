# Доработка анимаций и компактное окно

Проверка настоящего Qt Quick: **passed**. [Taste Skill](https://github.com/leonxlnx/taste-skill/blob/main/skills/taste-skill/SKILL.md) прочитан вместе с motion/icons/system/performance references. Применены единые параметры, короткие переходы без перелёта, движения transform/opacity и проверка реальной отрисовки. Его HTML/browser-gate неприменим к QML; вместо него выполнены проверки Direct3D11, QML-состояний и снимков.

## Выполненные требования

| Требование | Реализация |
|---|---|
| Наведение +3%, меньшая тень | Общий ButtonMotion: 1 → 1.03 за 150 мс. Смешиваются два кэшированных состояния тени: hover blur меньше на 14%, offset — на 15%. Раскладка не меняется. |
| Возврат к 100%, затем действие | 90 мс, InOutCubic. Обычные кнопки отправляют действие после возврата. У кнопки записи включён immediatePress: pressReady приходит сразу при нажатии, а визуальная анимация продолжается независимо. Быстрое отпускание также доставляется сразу, без повторного сигнала после анимации. |
| Значки из макетов | Десять контуров восстановлены из предоставленных изображений с трассировкой в 4-кратном разрешении. SVG — docs/design/reference-icons; PNG обоих цветов — outputs/source/assets/icons. |
| Одинаковые тени | Surface, кнопки, меню и внешняя панель: blur 22, offset 8, spread 1. Индивидуальные elevation/blur удалены. Плоские действия не получают фоновую карточку. |
| Детали | Проверены прозрачность плоских действий, фокус клавиатуры, отмена клика, раннее отпускание записи, последний аудиоблок, выбор меню, сохранение текста и HWND при смене темы. |
| Темнее в тёмной теме | Общая чёрная тень: alpha 0.14 в light и 0.34 в dark. Цвет участвует в общем переходе темы 320 мс. |
| Обводка темнее справа снизу | Bevel.qml: тонкое кольцо Shape с диагональным градиентом. Верхний левый участок светлый, нижний правый темнее. |
| Запись — только три точки | Размер, заливка, opacity, радиус и обводка кнопки не меняются. Подъём точек 10 единиц макета, сдвиг 130 мс, цикл 900 мс. Стоп-значок и пульсация удалены. |
| Без смены заливки при hover | Кнопки, переключатели и пункты меню сохраняют заливку; меняются только scale и состояние тени. Hover столбцов также не меняет цвет. |
| Copy/delete без рамок | Прозрачная поверхность, bevel выключен. Мышь не включает кольцо фокуса; общий motion применяется. Клавиатурный фокус остаётся видимым. |
| Без темы Windows | UI, контроллер и миграция допускают light/dark. Старое system трактуется как light. Плавная смена темы не пересоздаёт окно. |
| Окно меньше на 40% | Высота 850 × 0.6 = 510, ширина 392 логических пикселя. Размер ограничен рабочей областью. На коротком экране — вертикальная прокрутка с сохранением ширины и размера текста. |

## Проверки

- `tests/qml_motion_qa.py`: passed, без QML warnings и неожиданных сообщений об ошибках. В момент отложенного действия зарегистрирован scale **1.0**. Проверены также неизменная заливка, кэшированные тени, отмена, клавиатура, прозрачные icon-кнопки, поочерёдные точки, неизменный вид записи, QML hold-click с синтетическим аудио/ASR и последним аудиоблоком, две темы, одинаковые тени, сохранение текста и HWND.
- Все четыре экрана отрисованы в 392×510, 300×390, 600×780, 780×1014 и коротком 392×296. В коротком окне сняты верх и низ после прокрутки.
- 20 расчётных сочетаний: 1280×720, 1366×768, 1920×1080, 2560×1440, 3840×2160 при 100/125/150/200%. Стартовое окно помещается в рабочую область.
- `tests/qml_dpi_qa.py`: реальные процессы Qt с DPR **1.0** и **1.5**, все четыре экрана, стандартное/короткое окна и обе темы. Основная motion-проверка — с DPR **2.0**. Везде Direct3D11, без QML warnings.
- Локальный frameSwapped: медиана 16.53 мс, P95 25.35 мс. Это тестовое окружение с захватом снимков, не гарантия FPS на любом устройстве.
- `tests/qml_smoke.py`, 91 модульный тест, compileall, pip check, diff --check — успешно.

Артефакты: `work/qml-motion-qa/report.json`, снимки hover/press/recording и размеров, папки `dpi-1.0`, `dpi-1.5`. Временные данные не используются рабочим приложением. Новая версия открыта в уменьшенном окне. Прежний текст перед закрытием сохранён в локальном `work/qml-migration/restart-state.json`; новый ввод пользователя им не заменялся.

# VoxPad 0.6.3

Возвращён переносимый формат запуска как в 0.5.3. Текущий интерфейс Qt Quick, история, статистика и локальное распознавание Parakeet сохранены.

## Скачать и запустить

1. Скачайте **VoxPad-0.6.3-Windows-x64-portable.zip** из файлов этого релиза.
2. Выберите «Извлечь всё» и дождитесь полной распаковки.
3. Откройте папку VoxPad и запустите **VoxPad.cmd**.

Python, библиотеки и модель включены. Интернет во время запуска и диктовки не нужен. Для архива и распаковки оставьте не менее 4 ГБ свободного места. Не запускайте CMD прямо внутри ZIP.

## Что изменилось

- Включены последние правки капсулы: раскрытие из световой полоски, однократный блик по верхнему краю, свечение непрерывной волны без точек и плавное продолжение при быстром повторном нажатии. Появление и закрытие ускорены в 1,56 раза относительно первоначального варианта этой анимации.
- Собственный VoxPad.exe, загрузчик установки и NSIS-установщик не используются и не входят в этот комплект.
- VoxPad.cmd запускает оригинальный подписанный Python из папки runtime. При сборке проверяются подписи Python Software Foundation и RECORD-хеши зависимостей; исходные бинарные файлы поставщиков копируются без изменения.
- Полный комплект поставляется одним ZIP, проверяемым по SHA-256. Установочная загрузка с GitHub и её ошибка с журналом в TEMP в этом формате отсутствуют.
- Данные хранятся в data рядом с CMD; автозапуск выключен по умолчанию и доступен в настройках приложения.
- Для прежней ветки EXE-установщика подготовлены конкретные сообщения ошибок и отдельный журнал на случай отказа запуска worker. Эта ветка в данный релиз не включена.

## Обновление

Закройте прежний VoxPad через трей, распакуйте новую версию отдельно и скопируйте прежнюю data до первого запуска. Для установленной 0.6.2 это обычно `%LOCALAPPDATA%\Programs\VoxPad\data`. Если был включён автозапуск, выключите его в прежней версии и заново включите в новой папке. Подробности: [установка и обновление](https://github.com/Skrxtch-eds/VoxPad/blob/v0.6.3/docs/installation.md).

## Ограничения

Изменён способ распространения и запуска; подпись издателя VoxPad не добавлена. Сторонние DLL/PYD могут оставаться неподписанными. Работа на компьютере разработчика не гарантирует одинакового решения Defender / Smart App Control на каждом компьютере. Если Windows сообщает о блокировке, сохраните имя файла и текст уведомления. Настройки защиты сборка не меняет.

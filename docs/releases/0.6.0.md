# VoxPad 0.6.0

Локальная голосовая диктовка для Windows 10/11 x64.

## Скачать

- **VoxPad-0.6.0-Setup-x64.exe** — онлайн-установщик. Скачивает полный комплект с этого релиза, сверяет закреплённый SHA-256, устанавливает для текущего пользователя и создаёт ярлыки.
- **VoxPad-0.6.0-Windows-x64-runtime.zip** — полный комплект для portable и установки из локального ZIP.
- **.sha256** — контрольные суммы обоих файлов.

Откройте Setup, нажмите «Установить» и дождитесь завершения. Запустите VoxPad из меню «Пуск». После готовности модели поставьте курсор в Блокнот, зажмите правый Ctrl и произнесите фразу. Python, библиотеки и Parakeet включены. Для установки нужен интернет и не менее 4 ГБ свободного места, диктовка работает офлайн.

## Изменения

- Новый интерфейс Qt Quick с четырьмя экранами, светлой и тёмной темами.
- EXE-лаунчер поверх отдельного Python runtime.
- Онлайн-установка с проверкой целостности, ярлыками и удалением через Windows.
- Отдельное хранение файлов версии и общих пользовательских данных.
- Обновлённая капсула записи, сигналы и подготовка микрофона.
- Оптимизированный CPU-пайплайн и защита результата при сбое SQLite.
- Полная документация пользователя и разработчика.

## Данные и ограничения

История и настройки установленной программы находятся в %LOCALAPPDATA%\Programs\VoxPad\data. Удаление приложения сохраняет эту папку. Для переноса из portable скопируйте прежнюю data при закрытом приложении. При обновлении старые каталоги версий сохраняются.

Установщик и лаунчер пока не подписаны сертификатом издателя. Windows может предупреждать о неизвестном издателе. Частичная загрузка не возобновляется. Используется одна модель Parakeet, запись ограничена двумя минутами. Вставка зависит от активного окна и прав процессов. Локальная история не зашифрована.

Лицензия собственного кода пока не выбрана. Условия сторонних компонентов находятся в licenses и THIRD-PARTY-NOTICES.txt внутри ZIP.

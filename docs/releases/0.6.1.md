# VoxPad 0.6.1

Обновление безопасности и чистоты дистрибутива для Windows 10/11 x64.

## Скачать

- **VoxPad-0.6.1-Setup-x64.exe** — онлайн-установщик. Скачивает полный комплект, проверяет закреплённый SHA-256 и устанавливает программу для текущего пользователя.
- **VoxPad-0.6.1-Windows-x64-runtime.zip** — полный portable-комплект с Python, зависимостями и Parakeet.
- **.sha256** — контрольные суммы файлов.

Закройте прежний VoxPad через трей, запустите Setup, нажмите «Установить». Затем откройте ярлык VoxPad и дождитесь готовности. Для первой установки нужны интернет и не менее 4 ГБ свободного места. Диктовка работает офлайн.

## Исправления

- Runtime заменён на официальный Python 3.14.10 с проверкой подписей Python Software Foundation.
- Из дистрибутива исключены SSL-настройки и файл сертификата среды сборки.
- Pillow обновлён с 12.3.0 до 13.0.0 после проверки известных уязвимостей.
- Сохранение настроек ограничено известными полями, неизвестные данные старых настроек не переносятся при следующем сохранении.
- Скрипт публикации запрещает отправку GitHub-токена на посторонние адреса и перенаправления.
- В релизную проверку добавлен поиск секретов, лишних данных и известных уязвимостей пакетов.
- Удалён персональный локальный путь из текущего отчёта дизайна.

## Данные и ограничения

История и настройки установленной программы находятся в %LOCALAPPDATA%\Programs\VoxPad\data. Удаление приложения сохраняет эту папку. При обновлении сохраняются старые каталоги версий. При переносе из portable скопируйте data при закрытом приложении.

Установщик и лаунчер пока без сертификата издателя. Предупреждение Windows об неизвестном издателе возможно. История хранится локально без шифрования, текст копируется в системный буфер обмена. Проверка безопасности и её охват описаны в docs/security-review-2026-11-18.md в исходниках релиза.

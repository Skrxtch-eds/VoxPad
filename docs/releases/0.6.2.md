# VoxPad 0.6.2

Новый NSIS-установщик для Windows 10/11 x64 с минималистичным интерфейсом в стиле VoxPad.

## Скачать

- **VoxPad-0.6.2-Setup-x64.exe** — установщик. Скачивает приложение, Python, библиотеки и модель Parakeet с этого релиза, проверяет SHA-256 и устанавливает для текущего пользователя.
- **VoxPad-0.6.2-Windows-x64-runtime.zip** — полный portable-комплект. Извлеките всю папку VoxPad и откройте VoxPad.exe.
- **.sha256** — контрольные суммы файлов.

## Изменения

- Выбор папки установки: внутри выбранного каталога создаётся папка VoxPad. Итоговый путь виден до установки.
- Отдельные переключатели ярлыков на рабочем столе и в меню «Пуск».
- «Запуск вместе с Windows» включён по умолчанию. Выбор сохраняется и отображается в настройках приложения.
- Запуск из установленной папки, через ярлыки и при входе в Windows использует VoxPad.exe.
- Деинсталлятор удаляет программу и её интеграцию с Windows, сохраняя историю и настройки в data.
- Сохранены Qt Quick интерфейс, светлая и тёмная темы, локальная диктовка Parakeet на CPU и официальный Python 3.14.10 из предыдущих обновлений.

## Установка и обновление

Закройте прежний VoxPad через значок в трее. Откройте Setup, выберите папку и переключатели, нажмите «Установить». Для установки нужны интернет и не менее 4 ГБ свободного места. После установки диктовка работает без интернета.

Для обновления выберите родительскую папку существующей установки. История и остальные настройки сохраняются; настройка автозапуска применяется из установщика. По умолчанию данные находятся в %LOCALAPPDATA%\Programs\VoxPad\data. Старые каталоги версий сохраняются до удаления приложения.

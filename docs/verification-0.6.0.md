# Проверка VoxPad 0.6.0

Дата — 18 ноября 2026 года. Проверка выполнена локально на Windows x64.

## Результаты

- 126 модульных тестов прошли, включая регрессию гонки завершения очереди.
- QML smoke прошёл с Direct3D 11, без предупреждений Qt. Проверены навигация, смена темы без пересоздания окна, сохранение настроек, статистика и компактная геометрия.
- Полный portable ZIP извлечён в папку с кириллицей и пробелами. До запуска проверены SHA-256 всех 4732 файлов BUILD-MANIFEST.
- Комплектный Python запущен с очищенным PATH и посторонними PYTHONHOME/PYTHONPATH. Реальная модель загрузилась и распознала публичную русскую запись.
- Настоящий EXE-установщик прошёл установку из закреплённого локального ZIP, запуск через EXE-лаунчер, реальное ASR, повторную установку и удаление. Общая data сохранилась. Тестовый режим отключал регистрацию в Windows и ярлыки.
- Финальные Setup.exe и полный runtime проверены Microsoft Defender. Обе проверки завершились с кодом 0 и сообщением found no threats.
- GitHub Actions успешно выполнил Checks для основного коммита выпуска.

## Найденные и исправленные ошибки

В автономный runtime добавлен typing_extensions, необходимый установленной версии soundfile. Установщик получил поддержку длинных путей Qt. В контроллере исправлена гонка, при которой общая очередь могла забрать событие завершения раньше таймера выхода и оставить процесс работающим.

## Границы проверки

Это проверка на компьютере разработчика. Отдельная чистая виртуальная Windows, реальный микрофон, все приложения назначения и все конфигурации защиты не проверены. EXE пока без сертификата издателя. Результат Defender относится к проверенным файлам и текущим определениям.

Тестирование через локальный ZIP проверяет закреплённую контрольную сумму, распаковку и установку. Публичная онлайн-загрузка проверяется после публикации релиза. Личные тексты и история в дистрибутив не включены.

# Решение проблем

## Установка

В 0.6.3 установка не требуется: полностью распакуйте Windows-x64-portable.zip и запустите VoxPad.cmd. Собственного EXE-установщика в этом комплекте нет. Следующие сообщения и путь TEMP относятся к прежней EXE-установке 0.6.2.

Проверьте интернет, доступ к GitHub Releases и свободное место. При несовпадении SHA-256 повторите загрузку. Частичный файл удаляется. При необходимости передайте --archive=<путь к полному ZIP того же релиза>. Закройте старый VoxPad через трей. Отчёт тихой установки находится в %TEMP%\VoxPad-setup-error.log.

В опубликованной 0.6.2 сообщение «Проверьте интернет и свободное место» используется для любых ошибок worker. Оно само по себе не устанавливает причину. Сразу после неудачной установки нажмите Win+R и откройте `%TEMP%\VoxPad-setup-error.log`. Для разбора достаточно типа исключения и первой строки ошибки; имя пользователя и личные пути можно заменить на `***`. Если файл отсутствует, компонент установки мог не запуститься: проверьте сообщение Windows, .NET Framework 4.8 и журнал CodeIntegrity. Отсутствие журнала не доказывает конкретную причину.

В подготовленной диагностической сборке после 0.6.2 окно показывает этап, настоящую причину и результат сохранения журнала. Она также автоматически использует `VoxPad-<версия>-Windows-x64-runtime.zip`, если он лежит рядом с Setup. Проверка закреплённого SHA-256 обязательна. Эти правки ещё не входят в опубликованный Setup 0.6.2. [Пошаговая диагностика](windows-install-diagnostics.md).

## Запуск

Для portable 0.6.3 извлеките всю папку. Проверьте runtime, app, models и launch.py рядом с VoxPad.cmd. Ошибки Python находятся в data/startup-error.log. VoxPad-debug.cmd открывает диагностический запуск. Повторное открытие работающей программы показывает существующее окно. Если Windows сообщает о блокировке конкретного компонента, сохраните его имя и сообщение.

## Блокировка Windows

Если сообщение содержит «Интеллектуальное управление приложениями», это Smart App Control. Оно может блокировать неизвестные неподписанные EXE и DLL без обнаружения вируса. Setup и лаунчер опубликованной 0.6.2 не подписаны издателем. Сначала определите конкретный заблокированный файл: для неизвестного неподписанного компонента доверенная подпись является поддерживаемым способом устранения блокировки. Положительный результат антивирусного сканирования и перенос файла через ZIP не гарантируют разрешение SAC.

Разработчику нужен конкретный заблокированный файл из журнала событий: «Журналы приложений и служб → Microsoft → Windows → CodeIntegrity → Operational», событие 3077 (3076 в режиме оценки). Сохраните название файла, версию VoxPad и сообщение. Порядок исправления сборки описан в [документации подписи](windows-signing.md).

Сообщение «Система Windows защитила ваш компьютер» относится к SmartScreen и репутации файла/издателя. Обнаружение с именем `Trojan:…` или `Behavior:…` в журнале защиты Defender требует отдельного разбора по названию угрозы и SHA-256. Для старой 0.5.2 имеется [отдельный отчёт](defender-0.5.2.md).

## Микрофон и клавиша

Разрешите микрофон для классических приложений в настройках приватности Windows. Выберите вход в VoxPad и проверьте его в системных настройках звука. После переподключения USB/Bluetooth проверьте устройство повторно.

Дождитесь готовности модели и выключите паузу. При конфликте горячей клавиши назначьте другое сочетание. Кнопка микрофона позволяет проверить запись отдельно от глобальной клавиши.

## Вставка

Нажмите Ctrl+V в нужном поле или скопируйте текст из главного окна. Смена активного окна и удерживаемые служебные клавиши могут блокировать автоматическую вставку. Для приложения с повышенными правами могут потребоваться равные права VoxPad.

## Скорость и качество

Проверьте фоновую нагрузку CPU и качество звука. Первый запуск прогревает модель. Длинные записи обрабатываются дольше. Проверяйте имена, числа и термины перед отправкой важного текста.

## Обращение

Создайте Issue с версией, Windows, CPU, способом установки, шагами, ожидаемым результатом и текстом ошибки. Удалите личные тексты и ненужные локальные пути из вложений.

# Решение проблем

## Установка

Проверьте интернет, доступ к GitHub Releases и свободное место. При несовпадении SHA-256 повторите загрузку. Частичный файл удаляется. При необходимости передайте --archive=<путь к полному ZIP того же релиза>. Закройте старый VoxPad через трей. Отчёт тихой установки находится в %TEMP%\VoxPad-setup-error.log.

## Запуск

Для portable извлеките всю папку. Проверьте runtime, app, models и launch.py рядом с EXE. Ошибки Python находятся в data/startup-error.log внутри каталога версии, для portable — в data рядом с EXE. VoxPad-debug.cmd открывает диагностический запуск. Повторное открытие работающей программы показывает существующее окно.

## Блокировка Windows

Проверьте источник файла и сохраните название обнаружения, версию и SHA-256. Новые EXE пока не подписаны сертификатом издателя. Для старой 0.5.2 имеется [отдельный отчёт](defender-0.5.2.md). Сообщение об неизвестном издателе и обнаружение угрозы требуют разбора по точному тексту.

## Микрофон и клавиша

Разрешите микрофон для классических приложений в настройках приватности Windows. Выберите вход в VoxPad и проверьте его в системных настройках звука. После переподключения USB/Bluetooth проверьте устройство повторно.

Дождитесь готовности модели и выключите паузу. При конфликте горячей клавиши назначьте другое сочетание. Кнопка микрофона позволяет проверить запись отдельно от глобальной клавиши.

## Вставка

Нажмите Ctrl+V в нужном поле или скопируйте текст из главного окна. Смена активного окна и удерживаемые служебные клавиши могут блокировать автоматическую вставку. Для приложения с повышенными правами могут потребоваться равные права VoxPad.

## Скорость и качество

Проверьте фоновую нагрузку CPU и качество звука. Первый запуск прогревает модель. Длинные записи обрабатываются дольше. Проверяйте имена, числа и термины перед отправкой важного текста.

## Обращение

Создайте Issue с версией, Windows, CPU, способом установки, шагами, ожидаемым результатом и текстом ошибки. Удалите личные тексты и ненужные локальные пути из вложений.

# Данные и приватность

Распознавание выполняется локально через sherpa-onnx и Parakeet. Аудио и текст не отправляются во внешний ASR или облачную языковую модель. Обычная запись обрабатывается в памяти. Новое резервное аудио не создаётся.

## Сеть

Установщик загружает комплект с GitHub Releases и его CDN. При отсутствии модели приложение скачивает четыре файла с Hugging Face по закреплённой ревизии, сверяя размеры и SHA-256. Эти сервисы видят обычные сетевые сведения, включая IP. Отдельной отправки телеметрии в коде приложения нет.

## Хранение

Установленная программа использует %LOCALAPPDATA%\Programs\VoxPad\data. Portable использует data рядом с EXE. Исходники используют outputs/Transcriber/data.

settings.json содержит настройки. history.sqlite3 содержит последние 100 текстов и накопительную статистику. Эти файлы не зашифрованы приложением. При ошибке SQLite результат по возможности сохраняется в data/unsaved и повторно добавляется в историю при следующем запуске с защитой от двойного учёта.

Текст автоматически копируется в системный буфер. Настройки истории и синхронизации буфера Windows распространяются на него. Приложение назначения обрабатывает вставленный текст по своим правилам.

Для эффекта стекла индикатор записи берёт небольшой снимок области экрана под собой. Он остаётся в памяти и не сохраняется.

## Очистка и диагностика

Удаление записи убирает её из видимой истории SQLite. Для удаления всех локальных данных закройте VoxPad и удалите data. Это сбрасывает настройки и статистику. Остатки могут находиться в резервных копиях и системном буфере. Удаление программы сохраняет data. Старые файлы восстановления от прежних версий автоматически не удаляются.

--diagnostics <путь> включает локальные измерения без текста, аудио и названий окон. Логи ошибок могут содержать локальные пути. Проверяйте их перед публикацией в Issues.

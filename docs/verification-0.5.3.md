# Проверка переносимой сборки VoxPad 0.5.3

Дата: 1 ноября 2026 года. Проверки выполнены локально на Windows; файлы вручную во внешние сервисы не отправлялись.

## Изменение формата

Вместо собственного PyInstaller EXE поставляются открытые модули и отдельный Python 3.12.14. Исходные Python EXE/DLL скопированы без изменения; Authenticode исходных `python.exe`, `pythonw.exe`, `python312.dll` — Valid, издатель OpenAI OpCo, LLC. Настройки Defender и исключения не менялись. Сборка запускается через `VoxPad.cmd`, установка Python не требуется. Заблокированный EXE 0.5.2 не восстанавливался и не использовался.

## Результаты

- 47 модульных тестов прошли, в том числе масштабирование капсулы, корень данных и команда автозапуска нового формата.
- Microsoft Defender проверил всю подготовленную папку: `found no threats`, код завершения 0.
- Дополнительный диагностический запуск Defender с `-DisableRemediation` также сообщил `found no threats`, код 0. По документации Microsoft этот режим игнорирует файловые исключения и только выводит результаты, не меняя постоянные настройки защиты.
- После выполнения тестов в журнале Defender нет обнаружений для новой подготовленной папки и временно распакованной программы.
- Проверка готового ZIP сверила 3988 файлов с BUILD-MANIFEST до запуска и выполнила распознавание публичного английского WAV. Отдельный Python в системе не использовался; PATH содержал только Windows, посторонние PYTHONHOME/PYTHONPATH были проигнорированы.
- В отдельном обычном сеансе приложения успешно запустились трей и настоящий клавиатурный обработчик. Запись была выключена; микрофон, системный буфер обмена и настройки Windows в этом тесте не изменялись.
- Исправление размера капсулы относительно 2880 × 1920 и увеличение интерфейса на 50% входят в эту сборку.

VoxPad interface icons

Ten primary interface glyphs are traced from the reference artwork supplied by
the user for this application. Editable sources: docs/design/reference-icons.
Source crops, threshold and tracing settings: scripts/trace_reference_icons.py.

Phosphor Icons 1.3.0, Copyright (c) 2020-2021 Phosphor Icons.
https://github.com/phosphor-icons/phosphor-icons
MIT license: phosphor-license.txt

Unused/fallback Lucide sources are retained at docs/design/lucide.
Lucide 0.468.0: https://github.com/lucide-icons/lucide (lucide-license.txt).

PNG assets are rendered at 256 x 256 with QtSvg and QtAwesome 1.4.2.
QtAwesome is used only for asset generation, not by the running application.

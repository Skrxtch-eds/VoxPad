# VoxPad

Локальная голосовая диктовка для Windows 10/11 x64. Поставьте курсор в поле, зажмите правый Ctrl, произнесите фразу и отпустите клавишу. VoxPad распознает речь на CPU, скопирует результат и попробует вставить его в исходное окно.

Версия **0.6.3** использует PySide6 / Qt Quick, NVIDIA Parakeet TDT 0.6B v3 INT8 и sherpa-onnx. Интерфейс на русском языке, светлая и тёмная темы, история последних 100 записей, накопительная статистика, индикатор записи поверх других приложений.

## Скачать

**[Скачать полный ZIP для Windows x64](https://github.com/Skrxtch-eds/VoxPad/releases/download/v0.6.3/VoxPad-0.6.3-Windows-x64-portable.zip)**

1. Скачайте ZIP и выберите «Извлечь всё». Дождитесь полной распаковки.
2. Откройте извлечённую папку VoxPad. Python, библиотеки и модель уже включены.
3. Запустите `VoxPad.cmd`.
4. Дождитесь «Готово к записи» и попробуйте диктовку в Блокноте.

Это переносимый формат как в 0.5.3: установка не требуется, собственных VoxPad.exe и EXE-загрузчика в архиве нет. Интерфейс и возможности текущей версии сохранены. Интернет нужен только для получения ZIP; на другом компьютере можно распаковать заранее скачанный архив и работать офлайн. Для ZIP и распаковки оставьте не менее 4 ГБ свободного места. Запускать CMD прямо внутри ZIP нельзя.

Папки `runtime`, `app`, `models` и файл `launch.py` должны оставаться рядом с `VoxPad.cmd`. Настройки и история хранятся в `data` этой папки. Автозапуск выключен по умолчанию; его можно включить в настройках приложения. При обновлении распакуйте новую версию отдельно и перенесите прежнюю папку `data` при закрытом приложении.

В 0.6.3 убрана цепочка EXE-установки из 0.6.2. Оригинальные подписи Python и библиотек сохраняются, подпись издателя VoxPad не добавляется. Результат Smart App Control на конкретном компьютере зависит также от сторонних компонентов и политик Windows; универсальная гарантия запуска не заявляется. Если Windows сообщает о блокировке, сохраните имя файла и текст уведомления: [решение проблем](docs/troubleshooting.md).

## Использование

- По умолчанию запись идёт при удержании правого Ctrl. В настройках можно выбрать другую клавишу или режим переключения.
- Максимальная продолжительность записи — две минуты.
- Если вставка пропущена, нажмите Ctrl+V в нужном поле. Результат также доступен в главном окне.
- История хранит последние 100 расшифровок. Удаление записей сохраняет накопительную статистику.
- Закрытие окна при включённой фоновой работе оставляет приложение в трее. Для выхода используйте меню значка рядом с часами.

## Запуск из исходников

Нужны Windows x64, Python 3.14.10 x64 и микрофон.

```powershell
py -3.14 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe outputs\source\app.py
```

При отсутствии модели нажмите микрофон для её загрузки. Для следующих запусков используйте run.bat. Загрузка проверяет размеры и SHA-256 модели.

Лицензия собственного кода пока не выбрана. Лицензии сторонних библиотек и модели включаются в дистрибутив. Подробности приведены в [документации разработки](docs/development.md#лицензии).

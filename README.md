# VoxPad

Диктовка для Windows с локальным распознаванием речи на CPU. Зажмите правый Ctrl, скажите фразу и отпустите клавишу: текст появится в активном поле. Клавишу и режим записи можно изменить в настройках.

Приложение расшифровывает аудио и видео в TXT, хранит последние 100 расшифровок, восстанавливает прерванные записи и работает в трее. Есть русский и английский интерфейс, светлая и тёмная темы.

## Готовая программа

Версия 0.5.1 предназначена для Windows 10/11 x64. Переносимый архив `VoxPad-0.5.1-Windows-x64-portable.zip` собирается командой ниже; локально он находится в `outputs/`. Готовая программа публикуется в [релизах](https://github.com/Skrxtch-eds/VoxPad/releases).

Извлеките архив целиком и запустите `VoxPad/VoxPad.exe`. Python, библиотеки и модель Parakeet входят в сборку; интернет для диктовки не нужен. Папки `_internal` и `models` должны оставаться рядом с EXE. Не запускайте программу прямо из ZIP.

Архив занимает около 585 МБ. Для распаковки оставьте не менее 2 ГБ свободного места. Сборка не подписана цифровым сертификатом. Скачивание исходников через Code → Download ZIP не заменяет готовую программу.

## Запуск из исходников

Нужны Windows 10/11 x64, Python 3.12 x64 с Tkinter и микрофон. Другие ОС не поддерживаются: программа использует Windows API.

В папке проекта выполните:

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe outputs\source\app.py
```

После установки зависимостей приложение можно открывать через `run.bat` без консольного окна.

В разделе «Настройки → Распознавание» скачайте модель и нажмите «Выбрать модель». Доступны Parakeet v3 (около 487 МБ), Whisper Small (639 МБ) и GigaAM v2 для русского языка (172 МБ). Загрузка выполняется с GitHub проекта sherpa-onnx по команде пользователя. Модели не входят в исходники; для их загрузки нужен интернет. После установки выбранной модели распознавание работает локально, без отправки текста и аудио внешним сервисам.

## Использование и данные

- Для диктовки поставьте курсор в нужное поле и удерживайте правый Ctrl. Одна запись ограничена двумя минутами.
- История открывается через меню слева или левыми Ctrl + Shift + H. Записи можно искать, копировать и экспортировать.
- Для расшифровки файлов выберите папку экспорта и добавьте аудио или видео.
- Закрытие окна по умолчанию оставляет программу в трее. Для завершения выберите «Выйти» в меню значка рядом с часами.

Вставка в приложение, запущенное от администратора, может потребовать таких же прав у VoxPad.

В готовой сборке настройки, история и незавершённые записи хранятся в `data/` рядом с EXE, модели — в `models/`. При запуске исходников это `outputs/Transcriber/data/` и `outputs/Transcriber/models/`. Эти данные исключены из Git. При обновлении закройте VoxPad и сохраните `data/` и дополнительные модели.

## Сборка и проверки

Исходники находятся в `outputs/source/`. Для переносимой сборки сначала скачайте Parakeet через приложение:

```powershell
.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py"
.venv\Scripts\python.exe scripts\build_windows.py --format portable
```

Результат: `outputs/VoxPad-0.5.1-Windows-x64-portable.zip` и файл SHA-256. Сборщик включает только Parakeet; Whisper и GigaAM загружаются отдельно. Для установщика дополнительно нужен NSIS 3. UI-проверки, тест готового EXE и параметры сборки описаны в [заметках для разработки](docs/development.md).

Используются Tkinter, sherpa-onnx, sounddevice и PyAV. Версии зависимостей закреплены в `requirements.txt` и `requirements-build.txt`.

Лицензия собственного кода пока не выбрана. Условия сторонних компонентов и моделей приведены в [заметках для разработки](docs/development.md#лицензии); готовая сборка содержит их уведомления и лицензии.
